# StemMatch
An intelligent donor matching platform focused on HLA compatibility, scalable search, and explainable matching.

> **Educational / portfolio project — not for clinical use.**
>
> StemMatch is a software-engineering portfolio project. It is **not** a medical device, a clinical decision-support system, or a transplant recommendation tool, and it is not a substitute for qualified medical professionals or accredited histocompatibility laboratories.
>
> - The matching logic has **not** been clinically validated.
> - Match scores and explanations are illustrative outputs of a deterministic software rule set. They are **not** clinical probabilities or medical advice.
> - All donor and patient records in this project are **synthetic**. Public HLA nomenclature (allele names) is used only as reference data; no real person's HLA typing or identifiable information is used.

## Status

Early foundation stage. No services are implemented yet. See [docs/architecture.md](docs/architecture.md) for the proposed structure, ownership, and data-ownership model.
